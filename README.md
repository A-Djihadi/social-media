# social-media — visuels des publications

Dépôt d'hébergement des visuels destinés aux réseaux sociaux de Djihadi Ahamdy
(LinkedIn, Instagram, TikTok, X).

Il ne contient aucune donnée sensible : uniquement des images déjà produites pour
être publiées (PNG 2160x2700, format 4:5).

## Pourquoi un dépôt public

Les outils de programmation (Buffer, Postiz) et Notion exigent une URL HTTPS
publique et stable pour afficher ou publier une image. Un fichier rangé sur un
serveur, accessible seulement en SSH, ne peut pas être affiché depuis un
téléphone. Ce dépôt sert de stockage public minimal.

## URL d'un visuel

```
https://raw.githubusercontent.com/A-Djihadi/social-media/main/visuals/<fichier>.png
```

## Convention de nommage

`<reseau>-<AAAA-MM-JJ>-<sujet>.png`, en minuscules, sans accent.
Exemple : `linkedin-2026-11-24-homelab-1.png`.
